## 2. 已锁定

### 2.1 名称

- 中文：**守望者·汤和**（间隔号，非冒号）
- 英文：**The Watchman: Tang He**
- 目的：赛事主题词「守望」直接进标题；「汤和」是唯一检索关键词；英文副题 **Tang He** 让英文检索同样命中主角名。
- **语言：仅中文。** 不做英文本地化；英文名只用于标题、商店页与检索，不进入游戏内文案、UI 与字体子集。

### 2.2 题材与主角

- 主角**汤和**（1326—1395），封信国公，追封东瓯王，谥襄武。
- **洪武十九年（1386）**，汤和六十岁，奉诏赴东南沿海抗倭、修筑 59 座所城。
- 核心设定：**他老了，不能冲锋，只能布防。**

### 2.3 玩法定位

- **不是塔防，是要塞式的运营 + 守城。**
- 对标《要塞》（Stronghold）的**删减版**，但：
  - ❌ 不做自由砌墙的 3D 墙（无高度、无墙顶行走、无楼梯）
  - ✅ 改做 **2D 俯视网格 + 分段城墙**
- **不做真正的 RTS**：无编队、无科技树、无大地图寻路。
- **守方由玩家直接指挥**：点选单个单位、点地面移动、点登城点上墙；不画框、不编队（见 §2.21）。
- **关卡制**：每关是独立一局，地形、初始城墙、资源、波表、解锁顺序全部由关卡数据配置（见 §2.20）；不做跨关行军与资源继承。

### 2.4 视角与技术形态

- **2D 俯视图**，正交，非等距。
- 网格制，城墙可分段建造。
- 横屏 16:9。

### 2.5 美术：版画之城，活字之兵

| 层 | 负责 |
|---|---|
| **像素** | 城墙、城门、敌台、地形、水、血条、UI 边框 —— 只管形状 |
| **文字** | 所有单位、所有数字、所有旁白 —— 只管身份 |
| **Shader** | 纸纹、砖缝风化、水、火光、墨蚀、全局调色 |

**调色板固定 5 色**：墨 `#1f1b16`、朱 `#a4322a`、赭 `#8a5a3b`、靛 `#2f4858`、米白 `#efe6d2`

### 2.6 四种资源（仅此四种）

| 资源 | 主职 | 来源 | 用途 |
|---|---|---|---|
| **石** | **工事** | 采石场 | 城墙段、城门、敌台 |
| **木** | **民生** | 伐木场 | 一切建筑、弓弩、远程兵征兵 |
| **食** | **维持** | 田 | 养民、养兵、**征兵军饷** |
| **银** | **军事** | 房（按户缴税）+ 首级赏银 | **征兵军饷** |

**四种资源各有主职；唯一的交叉在「征兵」——同时吃银与食，远程再加木（见 §2.14）。**

- 断石 = 修不了墙、补不了段
- 断木 = 盖不了房、造不了弓弩、征不了远程
- 断食 = 饿死人，也征不了兵
- 断银 = 征不了兵

**核心分野：石管「防」，木管「长」。**

### 2.7 五座建筑 + 城防（仅此五座）

| 建筑 | 归类 | 造价 | 功能 | 岗位 |
|---|---|---|---|---|
| **田** | 民生 | 木 2 | 产食 | 3 民 |
| **房** | 民生 | 木 2 | 民上限 +2；每户产银 | — |
| **伐木场** | 民生 | 木 1 | 产木 | 2 民 |
| **采石场** | 民生 | 木 1 | 产石 | 2 民 |
| **兵营** | 军事 | 木 3（占位） | **征兵场所**：把 1 个民转化为 1 个兵 | — |

**城防单独归类**：城墙段、城门（含瓮城）、敌台不是「建筑」，不占建筑位，统一在底栏「城防」页签下操作（建墙 / 补墙 / 开合门）。

- **所有建筑都花木，只有城防花石。**
- **建造即时**：点选 → 放置 → 立刻完成，**不占民、不耗工期**；只在放置前校验资源与占位。
- **没有粮仓**：资源是纯数字，**无容量上限、可无限累积**；但饥荒按「当月收支 + 库存」判定（见 §2.11）。
- **没有大本营**：无主城血量，无「基地被毁」判负。
- **初始城墙不是固定的**：哪几段开局就存在、血量多少，由关卡数据决定（见 §2.20）；没配的段就是缺口。

### 2.8 民：两重身份 + 兵源

| 身份 | 内容 |
|---|---|
| **生产者** | 自动在田 / 伐木场 / 采石场工作 |
| **兵源** | 在兵营中转化为兵（兵不再生产，只吃粮；见 §2.14） |
| **失败条件** | **民 ×0 → 本局失败** |

- **不可操作**：不能点选、移动、指定工作（**只有兵可以被指挥**）。
- **会逃跑**：敌人靠近时往城里跑。
- **血格 3**，有独立血条，不换字。
- **基础民上限 8**，每座房 +2；征兵腾出 1 个上限位，遣散占用 1 个。

**分配规则（全自动）**：

```
优先填满「田」（保食）
余下的按建造顺序分到「伐木场」「采石场」
都满了 = 闲置（仍消耗食）
```

**兵营不占岗位**（只做征兵入口）；**建造不占民**（即时放置，见 §2.7）。

玩家用**建筑数量**控制分配比例，不用滑块。

### 2.9 核心循环

```
民 ──在田工作──▶ 食 ──养民 / 养兵──▶ 民
 │                                    │
 ├──在伐木场──▶ 木 ──建五座建筑 / 弓弩──┤
 │                                    │
 ├──在采石场──▶ 石 ──修墙 / 补段───────┤
 │                                    │
 └──住房──▶ 银 ──▶ 兵营：1 民 + 银 + 食（远程加木）──▶ 兵（也吃食，挤占民的粮）
                              │
                              ▼
                    守住 → 流民来投 → 民↑
                    守不住 → 民被吃 → 民↓ → 输
```

**关键张力：把民变成兵，等于把一张吃饭的嘴变成一张吃粮的嘴。** 每征一个兵，就少一个生产者、多一份军饷。

> **你必须征兵守城，但征兵会饿死你要保护的人。**

这是整个游戏的核心矛盾，也把「四丁抽一」经济化了。

### 2.10 数值模型（起始值，全部待调）

**结算单位：月。** 所有产出与消耗按月计。

| 项 | 值（除注明外均为每月） |
|---|---|
| 田 | 3 岗位 · 产 **15 食** |
| 伐木场 | 2 岗位 · 产 **9 木** |
| 采石场 | 2 岗位 · 产 **9 石** |
| 房 | 民上限 +2 · 产 **3 银** |
| 民 | 耗 **1.5 食** |
| 兵种 | 各耗 **1.5 食** |
| 兵营 | 不产资源、不占岗位；**征兵入口** |
| 征兵 | 一次性：**1 民 → 1 兵**，军饷 = 银 + 食（远程再加木），**具体值待定（§3.2 E4）** |
| 基础民上限 | **8**，每座房 +2 |
| 首级赏银 | 击杀 1 倭 **+1 银**，1 寇 **+2 银** |

**开局**：食 20 · 木 5 · 石 5 · 银 3 · 民 6（上限 8）

**换算口诀（做成新手提示）**：

> **一块田，净养活 7 个人。**

（15 食 ÷ 1.5 = 10 人；其中 3 人在田里干活，扣掉自身消耗，净剩 7 人的口粮。）

### 2.11 民心系统（对标《要塞》的民意）

民心是运营的**总健康度**，决定人口流入、流失、产出效率与是否怠工。

- 数值 0–100，开局 60
- **按月结算；不显示数字，显示为一个汉字**
- 时间单位「月」—— 时长待定（见 §3）

#### 月度结算

每月末依次结算：吃食 → 征税 → 民心变动 → 人口流动

```
民心变化 =
    食物项    ← 主导项
  + 税收项
  + 伤亡项    （本波阵亡人数）
  + 基准回正  （向 60 缓慢回归）
```

| 项 | 触发 | 方向 |
|---|---|---|
| **食物项** | 饱足 | 正 |
| | 紧张（吃库存） | 轻微负 |
| | **饥荒（库存 = 0）** | **强负** |
| 税收项 | 免税 / 低税 / 中税 / 高税 | + / + / 0 / − |
| 伤亡项 | 每阵亡 1 个民或兵 | 小负 |
| 基准回正 | 每月 | 向 60 靠近 |

> **食物项是主导项。** 粮食永远是民心最大的杠杆——与《要塞》一致：民以食为天。

#### 分档与消极影响

民心下降会**层层蚕食整个运营**：

| 档 | 民心 | 字 | 对运营的消极影响 |
|---|---|---|---|
| 一 | 80–100 | **安** | 无 · 流民来投（多） |
| 二 | 40–79 | **常** | 无 · 流民来投（少） |
| 三 | 15–39 | **怨** | 产出打折 · 停止来投 · 偶尔流失 1 民 |
| 四 | 1–14 | **散** | 产出大打折扣 · 每月流失民 · **兵营锁定（无法征兵）** |
| 五 | 0 | **怠** | **民集体怠工**（只吃不做，产出归零）· 大规模逃亡 |

> ⚠️ 各档位具体的折扣系数、流失人数、怠工触发线 —— **D12 平衡阶段再定**（见 §3 待定参数）。

#### 饥荒判定

每月结算时：

```
所需 = (民数 + 兵数) × 单位食耗
产出 = 田数 × 单田产出
结余 = 产出 − 所需
```

| 状态 | 条件 | 结果 |
|---|---|---|
| **饱足** | 结余 ≥ 0 | 民心 + |
| **紧张** | 结余 < 0，但库存 > 0 | 民心 轻微 − |
| **饥荒** | 库存 = 0 且结余 < 0 | 当月饿死民 · 民心 强 − |

#### 怎么"看得出来"

不靠数字，靠画面：

| 层 | 表现 |
|---|---|
| **顶栏** | 民心字：安 / 常 / 怨 / 散 / 怠，颜色随档递进（墨 → 赭 → 朱 → 更深） |
| **全局** | shader uniform `morale` 控制纸色去饱和、暗角加深 |
| **城内** | 墨点从民居升起（怨气粒子），密度 = 1 − 民心 |
| **民** | 「民」字变淡、轻微抖动 |
| **字幕** | 民心 < 40 时，每波开头发一句史料谣歌 |

谣歌素材（王钦豫《一笑录》）：

- 「米斗价逾五钱」
- 「比屋磬悬」
- 「饥民皇皇不能存活」

#### 怎么救

- **建田** —— 唯一长效解药
- **降税** —— 免税直接加民心
- **遣散** —— 兵 → 民，立刻减少粮食消耗（民心 < 40 且民上限有空位时按钮才出现）

> ⚠️ 田要木，木要伐木场。**饥荒的真正命脉是伐木场**——先保住它。

#### 税率

| 档位 | 银产出 | 民心方向 |
|---|---|---|
| 免税 | ×0 | 明显 + |
| 低税 | ×0.7 | 轻微 + |
| 中税 | ×1.0 | 0 |
| 高税 | ×1.6 | 明显 − |

> **每一档都是同一个赌博**：加税能立刻征兵，但民心往下掉；不征税手头宽裕，但下一波没兵挡。
> 具体系数归入 §3 待定。

#### 流民来投与流失

每月结算后按民心档位与城墙完好度修正人口：

| 城墙完好 | 修正 |
|---|---|
| 全好 | 按档位原值 |
| 半破 | 来投 −1 |
| 城破过 | 来投 0 |

（史载：永昌堡「孤城四面皆敌，避乱者万人」——这就是该机制的原型。）

### 2.12 城墙与上墙

**城墙最多 12 段**（每边 3 段）；史料「画城为十八号，每号五十丈」在此简化为 12 段。

- 四门位置固定（汤和规划的宁村所）
- **哪几段开局就有、血量多少，由关卡数据配置**；没配的段是缺口（见 §2.20）
- 空段由玩家花石**即时**建造；补墙同样即时结算石耗，不占民（§2.7）
- 每段有独立血量，可修补、可被攻破
- 某段被打穿 → 出现缺口 → 寻路更新

**上墙（核心机制）**

```
单位有 elevation：0 = 地面，1 = 墙顶
```

| 项 | 规则 |
|---|---|
| 登城点 | 每段墙 1 个（梯子符号） |
| 上 / 下墙 | 停留 **1.5 秒**，期间防御 −50% |
| 每段墙容量 | 2 个单位 |
| 视觉 | 脚下投影 + 字号大 1 档 + 米白描边 |

**墙顶加成**

| 项 | 地面 | 墙顶 |
|---|---|---|
| 射程 | 基准 | **+1 格** |
| 伤害 | 基准 | **+30%** |
| 被近战 | 可被攻击 | **免疫** |

**三条反制（防止无敌）**

1. **云梯** — 敌人爬墙成功 → 墙顶单位被近战，下墙需 1.5s
2. **敌方远程** — 弓对弓无高差优势
3. **火攻 / 撞塌** — 墙段血量归零 → 倒塌 → 墙上单位摔下，掉一格血

> 三条反制目前都还没有「载体单位」（攻方只有倭/寇/舟），由谁携带待定（§3.5 T1）。

> 加成是借来的，墙一塌就要还。

### 2.13 城门开合

> "进则可战，退则可守。" ——王叔杲

| 状态 | 你能做 | 敌人能做 |
|---|---|---|
| 门关 | 城墙上射击 | 撞门、爬梯 |
| 门开 | 义师出城野战 | 直接涌入 |

**每波都是同一个问题：要不要开门。**

- 城门属于**城防**归类，不占建筑位；**点门体直接切换开合**，不单设按钮（见 §2.18）。
- 东门「环海楼」的瓮城是否做实际机制（二道门 / 夹击区），待定（§3.5 T4）。

### 2.14 兵种

**守方 6 字**

| 字 | 定位 | 血格 | 退化链 | 征兵消耗 |
|---|---|---|---|---|
| **民** | 特殊（生产者 / 兵源 / 失败条件） | 3 | 民（不换字） | — |
| **兵** | 近战 · 高攻 · 低甲 · 薄血 · 快 | 2 | 兵 → 丘 | 1 民 + 银 + 食 |
| **弓** | 远程 · 远 · 低攻 · 低甲 · 薄血 · 快 | 2 | 弓 → 乙 | 1 民 + 银 + 食 + 木 |
| **弩** | 远程 · 短 · 高攻 · 高甲 · 厚血 · 慢 | 3 | 弩 → 奴 → 又 | 1 民 + 银 + 食 + 木（多） |
| **士** | 近战 · 高攻 · 高甲 · 厚血 · 慢 | 3 | 士 → 土 → 二 | 1 民 + 银 + 食（多） |
| **将** | 近战 · 中 · 有技能 | 4 | 将（不换字） | 唯一，开局给 |

> **征兵只在兵营里发生**：打开兵营 → 选兵种 → 消耗 1 个民 + 军饷（银 + 食，远程另加木）→ 该民原地变成兵。
> 军饷具体数值待定（§3.2 E4）。
> 兵可「遣散」回民（民心 < 40 时出现，需民上限有空位）。
> **「将」就是汤和本人**：只做指挥与自保，不主动冲锋；擂鼓 / 鸣金是他仅有的两个主动技。

**攻方 3 字**

| 字 | 定位 | 血格 | 退化链 |
|---|---|---|---|
| **倭** | 基础 · 快 · 脆 · 多 | 2 | 倭 → 委 |
| **寇** | 精英 · 血厚 · 一波一个 | 3 | 寇 → 完 → 元 |
| **舟** | 海上载兵 · 可被岸上弓弩击沉 | 3 | 舟（不换字） |

**「将」的技能**

- **擂鼓** — 周围单位攻速 +50%，持续 8 秒
- **鸣金** — **强制所有城外单位撤回城内，城门自动关闭**

> 「鸣金」是这套设计的题眼：进则可战、退则可守，在游戏里就是这两个按钮。

### 2.15 拆字退化

**血格数 = 字形阶数。** 血条掉一格，字就换一次形。

| 兵种 | 血格 | 字形阶段 |
|---|---|---|
| 民 | 3 | 民（不换字） |
| 兵 | 2 | 兵 → 丘 |
| 弓 | 2 | 弓 → 乙 |
| 士 | 3 | 士 → 土 → 二 |
| 弩 | 3 | 弩 → 奴 → 又 |
| 将 | 4 | 将（不换字） |
| 倭 | 2 | 倭 → 委 |
| 寇 | 3 | 寇 → 完 → 元 |

**规则**：血条是像素画的细分刻度，字形是同一个数据的放大刻度。**不做真实笔画擦除。**

**民的死亡反馈单独一套**（不换字）：
- 一声很轻的「啪」
- 字从中间被咬掉，留半个残字，停 2 秒才淡去
- 顶部数字 −1

> 别的单位死了是战损，民死了是这座城少了一口气。

### 2.16 叙事：一关 12 波，四段字幕

**每关一局，不切场景、不继承资源。** 一关仍是 12 波 + 四段章回字幕 + 四次机制解锁；解锁顺序与波表都是关卡数据，可按关卡改（见 §2.20）：

| 段 | 波次 | 字幕 | 解锁 |
|---|---|---|---|
| 一 | 1–3 | 卸甲归田心似箭　花甲重披旧战袍 | 田 / 房 / 伐木场 / 采石场 |
| 二 | 4–6 | 石臼门槛皆入城　小家大家总关情 | 城防建造（城墙 / 城门） |
| 三 | 7–9 | 四丁抽一民为兵　无事则耕有事战 | 税率 / 兵营（征兵） |
| 四 | 10–12 | 铁壁铜墙屹海滨　秋月春风斗古城 | 上墙加成 |

**每关 20–25 分钟。** 关卡数量与内容量待定（§3.5 T5）。

├──────────────────────────────────────────────────────────┤

│                                                          │

- **底栏分三页签**：民生（田 / 房 / 伐木 / 采石）、城防（城墙段 / 城门 / 敌台）、兵营（征兵）。一次只展开一页，保持「中部无遮挡」。

- **遣散按钮**仅在民心 < 40 且民上限有空位时出现（兵 → 民）
- 无仓库面板、无建筑详情、无建造进度条（建造即时完成）
- 数字跳动即反馈

### 2.19 平台与横屏

- **双端同源**：Windows + H5，一个工程、两个预设
- 横屏 16:9，基准 **1920 × 1080**，`canvas_items` 拉伸，宽高比 `expand`
  - 手机更宽（约 19.5:9）时多看到一些地图边缘，不出黑边
- **字体开 MSDF**，任意缩放不糊
- **地图方向**：正北朝上，**海在屏幕右侧**（东）

| 屏幕方位 | 城门 | 压力 |
|---|---|---|
| **右** | 东门「环海楼」（面海，瓮城） | **最大**，主攻方向 |
| **上** | 北门「通市楼」（通商，易渗透） | 中 |
| **下** | 南门「迎川楼」 | 中 |
| **左** | 西门「镇山楼」（背山） | 最小，退路 |

> 横屏后方位回归自然罗盘，不再需要旋转 90°。敌人从右侧海上推进，与横版阅读方向一致。

- **触摸优先**：不做拖框、不做悬停、不做右键。可点区 ≥ 96×96
- **横屏手机安全区**：避开左右刘海与底部手势条，UI 贴边留 4% 安全边
- **H5 硬性要求**：
  - 点击开始页（音频策略）
  - **竖持时提示「请横屏」**
  - 进入后调全屏 API（浏览器地址栏会吃掉垂直空间）
  - 单线程导出 / **字体子集化**
- **Windows**：默认窗口 1280 × 720，可缩放，可选全屏（不再有窗口放不下的问题）

### 2.20 关卡与关卡编辑器

**每关 = 一局**，可变内容全部外置为关卡数据，不写死在场景里：

| 数据 | 内容 |
|---|---|
| 城墙掩码 | 12 段中哪几段开局存在、各自血量 |
| 城门 | 四门初始开合状态 |
| 开局家底 | 石 / 木 / 食 / 银、民、已有建筑与兵 |
| 解锁时序 | 四个章回分别解锁什么 |
| 波表 | 12 波的敌人构成、方向、时刻 |
| 字幕 | 四段章回字幕与尾声文案 |

- **编辑器形态**：Godot 内置 `@tool` 面板，读写一份 JSON / Resource；也能手写 JSON 兜底。**限 0.5 天，超时立刻退回手写。**
- **不做**：大地图、跨关行军、关卡间资源继承。
- **关卡数量待定**（§3.5 T5）：先做 1 关完整可玩；第 2 关只是「换墙掩码 + 换波表」的验证，不新增机制。

### 2.21 单位指挥

- **能指挥的只有兵、弓、弩、士、将**；民始终不可操作。
- **点选单个单位**（不做框选、不做编队），点地面移动，点登城点上 / 下墙。
- **上墙占用**：每段上限 2 人、上下墙各 1.5 秒（§2.12）。
- **城门**：点门体开合；门开时敌我都能穿行。
- **将技**：擂鼓 / 鸣金两个入口的位置待定（§3.5 T2）。
- **桌面端**：鼠标 + 键盘快捷键（空格暂停、数字键切底栏页签）；H5 仅触摸，操作同构。
- **无阵型、无巡逻路线、无编队**——指挥粒度就是「一个个字」。
